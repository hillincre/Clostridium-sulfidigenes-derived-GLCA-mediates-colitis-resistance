# Clostridium-sulfidigenes-derived-GLCA-mediates-colitis-resistance
C. sulfidigenes protects mice from DSS- and Citrobacter rodentium colitis via bile salt hydrolase-derived glycolithocholic acid (GLCA). GLCA binds ILC3 GPRC5A, activating Gαi3–Hippo–YAP1–RORC to expand ILC3s and IL-22 barrier reinforcement; GLCA-trained ILC3 transfer protects, defining a GLCA–GPRC5A therapeutic axis.
